# Air Quality Index Monitoring & Prediction Dashboard

## 📌 Introduction

The Air Quality Index (AQI) Monitoring & Prediction Dashboard is a web-based project designed to monitor air pollution and predict future air quality. It displays AQI values and important pollutants such as PM2.5, PM10, CO, NO₂ and other air-quality parameters using simple charts and visualizations.

## 🎯 Objectives

- To monitor air quality in an easy way.
- To display AQI and pollutant information.
- To visualize air-quality data using charts and graphs.
- To predict future AQI levels.
- To create awareness about air pollution.

## 💡 Features

- AQI monitoring
- Air pollution data visualization
- Pollutant analysis
- AQI prediction
- Interactive dashboard
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Machine Learning

## ⚙️ How It Works

1. Air-quality data is collected.
2. The data is processed using Python.
3. Important pollutants are analyzed.
4. The prediction model predicts AQI levels.
5. The results are displayed on the Streamlit dashboard.

## 📊 Main Parameters

- PM2.5
- PM10
- CO
- NO₂
- SO₂
- O₃
- AQI
